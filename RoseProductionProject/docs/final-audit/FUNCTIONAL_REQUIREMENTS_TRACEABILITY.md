## Notes that do not change the statuses

- **FR-03.** Lot and variety are attributes of the crop; the user registers a harvest by choosing
  the crop whose label shows its variety and lot, and every harvest is displayed and returned with
  both. `FR-03-01` checked that the SQL join and the API return the same date, lot, variety and
  quantity.
- **FR-07/FR-08.** The method is defined and reproducible, but its accuracy is **not** established:
  on the real data only one forecast (#1: 1,550 vs 1,600, MAE 50, MAPE 3.13 %) has an actual harvest.
  A forecast is evaluated only when a harvest exists for the same crop on exactly the forecast date
  (design of `vw_forecast_status`). The moving average does not model trend or seasonality.
- **FR-09 vs data consistency.** Referential integrity holds. Logical inconsistencies that are not
  referential (harvests 16, 17, 18 and forecast 7 dated before their crop was planted; two harvests
  for one crop and day) are evaluated under NFR-02.
- **Pre-existing data was not modified.** All test rows were created and deleted by the tests
  (`GUARD-01`, `test_zz_production_data_guard`, GUI-25).
